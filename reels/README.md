# Swipex — Instagram Reels

Три рілси 1080×1920, 30 fps (HTML + GSAP → MP4 через Playwright та ffmpeg).
Бренд узято з Figma «Social Media (Instagram)»: Inter, `#0ABB87`, `#0B0B0B`, `#F5F5F5`, `#B8B8B8`.

| Файл | Ідея | Референс |
|---|---|---|
| `out/01-idea-to-product.mp4` | Кінетична типографіка: «Є ідея? → Ми зробимо продукт» → 4 кроки процесу → логотип і CTA | Brander |
| `out/02-grid-story.mp4` | Зелена сітка 3×5, плитка з логотипом проїжджає рядком і лишає за собою «Swipex × проєкт» | Giti × VW |
| `out/03-b2b-cards.mp4` | «Топ-3 помилки в B2B-платформах»: 3D-картки над перспективною сіткою, що збираються у плитку-лого | Parasail |

Рендер: `npm i gsap @fontsource/inter playwright`, потім `node render.mjs 01-idea-to-product 30`.
Логотип у `logo.js` перемальований вручну — замініть на офіційний SVG.

| `out/06-flythrough.mp4` | Камера летить крізь 3D-світ із вирізками | Parasail |
| `out/07-brand-world.mp4` | Густе поле дрібних вирізок (екрани проєктів, команда, 3D-елементи, іконки) і політ у «героя»: чорна плитка з логотипом → чорне тло, біла картка → біле тло | Parasail |

Усі телефонні мокапи — один компонент iPhone 16 (`phone.js`) зі статус-баром, Dynamic Island і індикатором «Додому».

| `out/08-card-field.mp4` | Точне відтворення механіки референсу 2822: поле плоских карток (портрети команди, піктограми з крапок, світлові вивіски, постер, «книга», UI, телефон iPhone 16, вікно Medis, зелені плитки з логотипом). Камера по черзі в'їжджає в картку-героя (~0,25 с на переїзд), на зеленій плитці тло різко перемикається біле → чорне, послідовність повторюється, на фіналі тло знову біле й лишається логотип з назвою | Parasail |
